Moringa School Phase1 Project

The project is based on Aviation Accident Analysis for dataset ranging (1962–2023). The data was sourced from National Transportation Safety Board (NTSB) accident reports (1962-2023). 
Aimed at providing data-driven insights to support decision-making for efforts to reduce air accidents
Key Deliverables: include a README Repository, a jupyter notebook, a non-technical presentation and interactive dashboard
Understanding aviation accident trends is a key initiative that would improve safety and operations.
Some of the analysis that has been achieved include accident events over the years provided, understanding the role of weather as well as the make of aircraft, visualizing how the phase of flights contribute to accidents
The data provided included Accident date, location, aircraft type, causal factors, and fatalities.
Data Challenges addressed include missing and duplicates values.
Some recommendation for future analysis would be availability of spatial data where the incidents happened so that the information can be represented on a map for visualization
Another key aspect is the inclusion of pilot errors and contributions to airplane accidents. That would also inform their training programs
Using the analysis, one can get a highlight of aircraft make that are more susceptible to accidents and thus have a targeted evaluation to see if it is mechanical oriented
